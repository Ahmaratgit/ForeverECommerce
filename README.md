# Forever E-Commerce ウェブサイト
Foreverは、男性・女性・キッズ向けのトレンディな服を販売するEコマースサイトです。  
主な機能:
- カテゴリごとの商品閲覧
- カートに追加して購入
- 代引き (Cash on Delivery) & 7日間の返品対応
- お客様レビュー
- モバイル・デスクトップ対応のレスポンシブデザイン

## 技術スタック
- HTML, CSS, JavaScript
- React.js
- Node.js（バックエンド）
- Tailwind CSS
